🌾 Farmer Helper – Smart Agriculture Support System

Farmer Helper is a web and mobile application designed to empower farmers with easy access to agricultural information and digital tools.
The platform helps farmers identify crop diseases, find suitable seeds, view import/export market prices, and explore various agricultural resources — all in one place.

🔑 Key Features

🧠 Crop Disease Information: Get detailed info on symptoms, causes, and treatments for major crop diseases.

🌱 Seed & Tool Suggestions: Discover the best seeds, fertilizers, and tools for different crops.

💹 Market Price Tracker: Stay updated with real-time import/export and local market prices per crop.

🌍 Farming Resources: Access guides, weather info, and government schemes related to agriculture.

📱 User-Friendly Interface: Simple design for easy use by farmers in regional languages.

🚀 Tech Stack

Frontend: HTML, CSS, JavaScript (React or Vanilla JS)

Backend: Firebase / Node.js

Database: Firestore / Realtime Database

APIs: Market price & weather data integration

🎯 Goal

To help farmers make smarter decisions, increase productivity, and connect them with global agricultural insights through one digital platform.
